# Technical Writing Lab

This repository contains my work and learning documentation for the **Technical Writing Lab** course at **Malaviya National Institute of Technology (MNIT), Jaipur**, Department of Computer Science and Engineering.

It includes the source code and outputs of the lab assignments, along with documentation of the concepts covered during lectures and practical sessions.

The documentation is divided into two sections:

- **Topic-wise Documentation:** Notes covering the tools and technologies studied throughout the course.
- **Assignment-wise Documentation:** A summary of the concepts and practical work completed in each assignment.

---

## 1. Topic-wise Documentation

These documents cover the concepts learned during the course, with explanations, commands, and examples wherever relevant. They are based on the lecture slides and practical assignments.

| Topic | Description |
|---|---|
| [LaTeX](documentation/topics/LaTeX.md) | Introduction to LaTeX, document structure, classes, packages, mathematical expressions, tables, figures, lists, colours, boxes, citations, bibliography, and indexing. |
| [Beamer](documentation/topics/Beamer.md) | Creating presentations using LaTeX, including frames, themes, blocks, columns, headers, footers, and slide numbering. |
| [Doxygen](documentation/topics/Doxygen.md) | Documenting C++ source code using comments and Doxygen tags, configuring a Doxyfile, and generating HTML and PDF documentation. |
| [Google Docs](documentation/topics/Google-Docs.md) | Document formatting, paragraph styles, tables, collaboration, sharing permissions, comments, suggestions, and version history. |
| [Git](documentation/topics/Git.md) | Version control fundamentals, repositories, staging, commits, branches, merging, undoing changes, viewing history, and stashing. |
| [GitHub](documentation/topics/GitHub.md) | Remote repositories, connecting local repositories, cloning, pushing, pulling, forking, branches, and pull requests. |
